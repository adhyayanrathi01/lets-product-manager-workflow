# Orchestration rules

- Frame each initiative around a decision the PM needs to make.
- Create a project folder for substantial work.
- Plan only the evidence tracks relevant to the decision.
- Route support-ticket requests to analyze-support-tickets, meeting requests to analyze-meetings, and team communication requests to analyze-team-communications.
- Use those skills independently for narrow requests or combine their outputs through run-product-workflow for broader investigations.
- Delegate independent tracks when subagents are available.
- Synthesize results into facts, hypotheses, options, uncertainty, and trade-offs.
- Stop for the PM’s decision before implementation or external changes.
