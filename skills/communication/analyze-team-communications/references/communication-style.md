# Communication style

Use the company-specific communication guidance in context.md when it exists. Otherwise use these defaults.

## Default style

- Be concise, direct, respectful, and evidence-led.
- Lead with the purpose, decision, or requested action.
- Separate decisions, evidence, risks, questions, and action items.
- Name owners and dates only when they are confirmed.
- State uncertainty instead of hiding it.
- Prefer plain language over jargon or corporate filler.
- Match the detail level to the audience and channel.
- Preserve material disagreement without making it personal.
- Avoid inferring tone, emotion, or intent from short messages.

## Drafting boundary

Any generated message, email, update, or meeting summary is a draft until the user explicitly approves sending it. Never imitate a private individual’s personal style or expose private-channel content to a broader audience.
